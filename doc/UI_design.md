这个设计方向非常棒。“莫兰迪绿 + 更加克制硬朗的线条” 会给 LightTable 带来一种高级的、杂志般的、甚至带有某种“禅意”的秩序感。这非常符合“整理冰箱、净化生活（熵减）”的产品哲学，同时也完全避开了那种花哨的科技感（Vibecoding）。

以下是为你定制的 UI/UX 设计规范文档。

LightTable UI 设计规范 (Morandi Edition)
1. 核心视觉体系 (Visual Identity)
色彩系统：莫兰迪绿 (Morandi Green Theme)
我们要营造一种**“冷静、健康、有机”**的氛围。没有高饱和度的色彩，所有颜色都像是蒙了一层灰调。

主色 (Primary): Sage Green (鼠尾草绿)

色值参考：#7C9082

用途：主要按钮背景、Tab 选中状态、重要图标。

背景色 (Background): Pale Mist (极淡的雾青色)

色值参考：#F5F7F6 (不要纯白，要带一点点冷暖的纸张感)。

用途：全局页面背景。

卡片/表面色 (Surface): Pure White

色值参考：#FFFFFF

用途：食材卡片、弹窗背景。

文本色 (Text): Deep Charcoal (深炭灰)

色值参考：#2F3A35 (不是纯黑 #000000，带一点绿调的深灰，阅读体验更柔和)。

警告色 (Alert): Muted Clay (哑光陶土色)

色值参考：#C97C74 (用来替代刺眼的大红色，标记过期食材)。

辅助灰 (Neutral): Stone Grey

色值参考：#D1D6D3 (用于分割线、未选中图标)。

形状与质感 (Shape & Texture)
拒绝： 任何形式的渐变 (Gradient)、毛玻璃 (Glassmorphism，除非极必要)、全圆角按钮 (Pill Shape)。

采用：

全实色填充 (Solid Flat Color)：色块清晰有力。

微圆角 (Squircle/Small Radius)：所有卡片和按钮使用 8px - 12px 的圆角。这显得更结构化、更现代、更稳重。

细边框 (Hairline Borders)：卡片使用 1px solid #E5E7E6 的边框，代替阴影来区分层级。

2. 组件样式详解 (Component Styles)
A. 按钮 (Buttons)
主按钮 (Primary Action)

样式：实心填充 #7C9082，文字白色。

形状：矩形微圆角 (Rounded Rectangle)，border-radius: 8px。

高度：48px (适合手指点击的标准高度)。

交互：点击时颜色变深 10% (无涟漪动画，无缩放，要干脆)。

次级按钮 (Secondary Action)

样式：透明背景，1px 实线边框 (#7C9082)，文字绿色。

幽灵按钮 (Ghost Button)

样式：仅文字，加下划线或加粗，用于“取消”或次要链接。

B. 导航栏 (Bottom Navigation)
背景：纯白不透明 (#FFFFFF)，顶部有一条极细的灰色分割线。不使用半透明模糊，强调稳固感。

图标：使用 Lucide React 的图标库，线宽设置为 1.5px (细线条)，显得精致。

选中态：图标和文字变为莫兰迪绿，图标上方或下方不需要加点，通过颜色区分即可。

C. 食材卡片 (Ingredient Card)
布局：列表式 (List View) 或 网格式 (Grid View)。

样式：白色背景，1px 极淡的灰色边框，无阴影 (Flat)。

信息层级：

左侧：食材缩略图 (正方形，radius: 6px, object-fit: cover)。

中间：食材名称 (加粗深灰) + 数量 (小字浅灰)。

右侧：状态标签 (Tag)。

状态标签样式：不使用实心色块，使用 “浅色背景 + 深色文字”。

例如：临期 -> 背景 #F2E6E5 (淡红)，文字 #C97C74 (陶土红)。

3. 用户点击路径与布局 (User Flow & Layout)
场景一：打开冰箱 (Homepage / Inventory)
这是用户最高频查看的页面。

Header (顶部)

左侧：大标题 "LightTable" (Serif 衬线体或粗体 Sans)，深灰色。

右侧：“添加”按钮。

设计点：不要做成悬浮球 (FAB)。做成一个 右上角的文字按钮 或 Header 里的图标按钮 (相机 Icon)。保持页面平整。

Body (内容区)

顶部是一个 “概览条” (Summary Bar)：显示 "3 个食材即将过期" (陶土色背景条，提醒但不刺眼)。

下方是 食材列表。

空状态：屏幕中央显示一个线条风格的简笔画插图 (如一个空的盘子)，配文 "冰箱空空如也"。

场景二：录入食材 (Add Item Flow)
用户点击右上角“相机”后：

触发系统相机 (Web 端 <input> 调用)。

预览页 (Preview Overlay)：

照片占据屏幕上半部分。

下半部分滑出一个 白色面板 (Sheet)。

面板内显示：正在识别... (Loading) -> 识别结果列表。

用户可以点击列表项修改数量。

确认动作：

底部通栏按钮 (Full Width Button)："放入冰箱" (确认入库)。

场景三：生成决策 (Decision Flow)
这是 App 的核心智能体现。

Tab 切换：点击底部的 "Decide" 图标。

输入态：

页面显示：“想怎么吃？”

提供几个 Tag 胶囊 供选择：#消耗临期 (默认选中), #减脂, #快手菜。

按钮："开始规划" (Sage Green 实心按钮)。

生成态 (Agent Thinking)：

屏幕中间出现简单的打字机效果日志：

正在检查库存...

检索 Mem0 记忆：你不吃姜...

正在生成食谱...

结果态 (Results)：

展示 3 张 食谱大卡片。

卡片布局：

顶部：菜品名称 (如 "小炒黄牛肉 - 减脂版")。

中间：核心食材 (高亮匹配的库存)。

底部：一行小字理由 ("完美消耗了你的芹菜")。

交互：点击卡片进入详情。

场景四：食谱详情 (Recipe Detail)
布局：

像一张购物小票或烹饪指南卡。

背景可以是极淡的暖白色。

标题区：菜名 + 预计时间。

中间：分割线。

步骤区：步骤前使用数字序号，步骤文本行间距调大 (leading-loose)，方便阅读。

底部：两个并排按钮。

左侧 (Ghost)："换一个"。

右侧 (Primary)："开做" (点击后扣减库存)
