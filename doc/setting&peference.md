这份 PRD 专注于 “设置 (Settings)” 模块。在 LightTable 中，设置不仅仅是更改开关，更是用户**“调教” Agent 大脑（Mem0）** 的核心入口。我们需要保持设计的克制感（Morandi Flat Style），同时在功能上满足 RAG 系统所需的上下文输入。产品需求文档 (PRD)：设置与偏好管理 (Settings & Preferences)模块名称Settings (Me)优先级P0 (核心功能)涉及 AgentMem0 (Memory Engine), Coordinator Agent设计风格Morandi Flat (硬朗、克制、列表式)1. 页面概览 (Page Overview)设置页采用经典的 “分组列表 (Grouped List)” 布局，类似于 iOS 原生设置。背景色为 Pale Mist (#F5F7F6)，列表项为纯白 Surface (#FFFFFF)，通过 1px 极细边框分割。核心功能区块：身体档案 (Body Profile): 基础生理数据。饮食偏好 (Dietary Logic): 直接写入 Mem0 的长期记忆。系统设置 (System): 提醒与显示。调试与演示 (Debug & Demo): 课程作业专用的“作弊模式”。2. 详细功能需求 (Functional Requirements)2.1 头部区域 (Header)UI: 简单的顶部栏，大标题 "Me"。Action: 无（设置页通常是顶层页面）。2.2 第一组：身体档案 (Body Profile)用于计算基础代谢率 (BMR)，辅助 RAG 推荐热量合适的食谱。UI 组件: ListItem (Label + Value + Chevron Right)。交互: 点击行，从底部滑出 Sheet (半屏弹窗) 进行修改。数据项:性别 (Gender): 单选 (Male / Female / Other)。年龄 (Age): 滚轮选择器 (Picker) 或 输入框。身高 (Height): cm。体重 (Weight): kg。目标 (Goal): 单选卡片。减脂 (Fat Loss) - Sage Green 高亮维持 (Maintain)增肌 (Muscle Gain)2.3 第二组：Agent 调教 (The Brain Configuration)这是本页面的核心。用户的每一次修改，都会触发后端调用 Mem0 的 add() 接口，更新用户画像。忌口管理 (Dislikes / Allergies)UI: 点击进入二级页面。交互:顶部输入框 + "添加"按钮。下方展示已添加的标签 (Tags)。标签样式：矩形，淡红背景 (bg-red-50)，深红文字 (text-red-800)，带 'X' 删除号。逻辑: 删除标签时，需调用 Mem0 删除对应记忆。口味偏好 (Flavor Profile)UI: 多选标签组 (Chips)。选项: 清淡, 重口味, 辣, 酸甜, 低碳水, 高蛋白。选中态: bg-primary (Sage Green) + text-white。厨艺水平 (Cooking Level)UI: Segmented Control (分段控制器)。选项:生存 (Survival): 只会煮泡面/微波炉。家常 (Home Cook): 能炒菜 (默认)。大厨 (Chef): 拥有烤箱、空气炸锅等复杂设备。2.4 第三组：系统 (System)临期提醒 (Expiry Alert)UI: ListSwitch (文字 + 开关)。逻辑: 开启后，如果库存中有 expiry_date <= 2 days 的食材，Inventory 图标显示小红点。清除缓存 (Clear Cache)UI: 普通列表项，点击弹出 ConfirmDialog。逻辑: 清空本地存储，但不删除后端数据库。2.5 第四组：开发者与演示 (Demo / Debug)此区域在课程演示时至关重要。Agent 思考可视化 (Show Agent Thoughts)UI: ListSwitch (开关)。逻辑:OFF (默认): 用户点击“决策”只看到结果。ON: 全局开启 DebugOverlay 组件。在任何页面（尤其是决策页），屏幕下方会悬浮一个半透明黑色终端窗口，实时打印 RAG 检索过程 (e.g., [LlamaIndex] Retrieving..., [Mem0] Found user dislikes ginger...)。重建知识库 (Rebuild RAG Index)UI: 幽灵按钮 (文字红色)。逻辑: 点击后调用 POST /api/v1/rag/rebuild，强制后端重新读取 recipes.json 并生成向量索引。防止演示时搜不到刚加的数据。3. UI 样式规范 (UI Specifications)3.1 列表项组件 (SettingsRow)高度: 56px。背景: 纯白 (bg-white)。边框: 仅底部有 1px 边框 (border-b border-zinc-100)，最后一项无边框。字体:Label: text-main (#2F3A35), font-medium, text-base.Value (右侧): text-muted (#8B9691), text-sm.Icon: 左侧可选 Icon (Lucide)，大小 20px，颜色 text-primary (#7C9082)。3.2 分组容器 (SettingsGroup)外边距: mb-6 (组与组之间留白)。圆角: rounded-xl (不要用 full，保持 12px 左右)。溢出: overflow-hidden (确保子项边框不溢出)。4. 数据交互逻辑 (Data Logic)4.1 获取设置 (GET /api/v1/user/profile)页面加载时调用。JSON{
  "profile": { "height": 175, "weight": 70, "goal": "fat_loss" },
